# Comprovantes de Pix de exemplo — FICTÍCIOS

Cada arquivo imita a **estrutura** do comprovante de um banco (ordem dos campos,
rótulos, quebras de linha, formato de data/valor/ID), no formato em que o leitor
recebe o texto (uma linha visual por linha; colunas separadas por 3+ espaços).

Todos os nomes, valores, CPFs, contas e IDs são **inventados**. Nenhum dado real
de comprovante é guardado no repositório.
